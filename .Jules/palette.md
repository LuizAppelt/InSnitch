## 2024-05-14 - Improve Focus Styles and ARIA labels for Icon-Only Buttons
**Learning:** This app frequently removes default focus outlines using `focus:outline-none` on interactive elements (inputs, selects, buttons). Without restoring them via `focus-visible:ring-*`, keyboard navigation becomes invisible, severely impacting accessibility. Additionally, modal close buttons and sidebar action buttons frequently rely on icons alone (like `data-lucide="x"`) and lacked `aria-label` attributes, making them inaccessible to screen readers.
**Action:** When styling with Tailwind in this project, explicitly add custom focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`) to interactive elements that use `focus:outline-none`. Always ensure icon-only buttons include descriptive `aria-label`s.
