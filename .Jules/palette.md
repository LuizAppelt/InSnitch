## 2026-09-17 - Responsive Navigation & Focus Rings
**Learning:** The application uses responsive design classes like `hidden md:inline` to visually hide text in navigation menus on mobile screens. This leaves icon-only elements that are inaccessible to screen readers. Also, many interactive elements deliberately hide default focus states using `focus:outline-none` without providing visual focus indicators, disrupting keyboard navigation.
**Action:** When adding or updating interactive elements, especially responsive menus that collapse text, always explicitly add descriptive `aria-label` attributes in Portuguese. For elements that use `focus:outline-none`, remember to add custom focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`) to preserve keyboard accessibility.
