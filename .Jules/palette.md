## 2024-11-10 - Screen Reader Accessibility and Custom Focus Rings
**Learning:** Using `hidden {breakpoint}:inline` on text labels inside icon buttons removes the text from screen readers completely on mobile devices. If there's no `aria-label`, this makes the buttons inaccessible. Tailwind's `sr-only {breakpoint}:not-sr-only {breakpoint}:inline` pattern is a better approach than adding redundant `aria-label`s when the text label already exists but is visually hidden on smaller screens. Additionally, elements styled with `focus:outline-none` often lose their default browser focus ring, breaking keyboard accessibility.
**Action:** When hiding text labels responsively, use `sr-only {breakpoint}:not-sr-only {breakpoint}:inline` instead of `hidden md:inline` to ensure screen readers can announce the text even when visually hidden. When removing default outlines (`focus:outline-none`), always provide a custom focus state (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`) to maintain keyboard navigation accessibility.
