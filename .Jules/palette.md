## 2026-09-07 - [Focus Outline Visibility]
**Learning:** When using Tailwind's 'focus:outline-none' on interactive elements (like selects and inputs), native keyboard focus indicators are lost. This hurts keyboard accessibility.
**Action:** Always complement 'focus:outline-none' with a custom focus ring, e.g., 'focus-visible:ring-2 focus-visible:ring-ig-primary', to ensure keyboard users can navigate effectively.
