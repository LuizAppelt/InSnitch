## 2024-05-15 - [Add focus rings to focus:outline-none elements]
**Learning:** When styling with Tailwind in this project, explicitly add custom focus rings (e.g., 'focus-visible:ring-2 focus-visible:ring-ig-primary') to interactive elements that use 'focus:outline-none' to ensure they remain keyboard accessible.
**Action:** Apply 'focus-visible:ring-2 focus-visible:ring-ig-primary' (or similar) whenever 'focus:outline-none' is used on an input or select.
