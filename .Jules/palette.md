## 2024-05-24 - Accessibility on Mobile Navigation & Focus States
**Learning:** Responsive classes like `hidden md:inline` make text completely inaccessible to screen readers on mobile devices because `display: none` removes the element from the accessibility tree. Thus, icon-only buttons on mobile need explicit `aria-label` attributes to remain accessible. Furthermore, when overriding default focus styles with `focus:outline-none`, keyboard navigation feedback is lost unless explicit focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`) are added.
**Action:** Always verify that interactive elements with visually hidden text on mobile have appropriate `aria-label`s. Whenever applying `focus:outline-none`, accompany it with a `focus-visible:` utility to preserve keyboard accessibility.
