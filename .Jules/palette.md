## 2024-05-24 - Accessibility and Keyboard Navigation Polish
**Learning:** Many interactive elements (buttons, inputs, selects) in the dashboard utilize Tailwind's `focus:outline-none` to hide default browser focus styles but missed implementing a custom focus indicator, making keyboard navigation virtually impossible to track visually. Furthermore, various inputs, selects, and icon-only modal close buttons lacked associated `label` tags or `aria-label` attributes, creating a poor experience for screen reader users.
**Action:** When styling with Tailwind and using `focus:outline-none`, always pair it with explicit custom focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`). Always verify that icon-only buttons and form elements lacking visible `<label>` tags receive an appropriate `aria-label` to ensure context for assistive technologies.
