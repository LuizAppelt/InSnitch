## 2024-05-20 - Focus styles on select menus\n**Learning:** When styling select menus with Tailwind, they might be relying on default focus outline which we often remove with `focus:outline-none`. Interactive elements using this must have `focus-visible:ring-2 focus-visible:ring-ig-primary` to remain accessible to keyboard users.\n**Action:** Add custom focus rings to any element using `focus:outline-none`.
