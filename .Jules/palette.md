## 2024-05-17 - Improve Accessibility for Mobile Screen Readers and Keyboard Navigation
**Learning:** Found that navigation buttons using `hidden md:inline` for their text labels lacked `aria-label` attributes, making them inaccessible to screen readers on mobile devices where the text is hidden. Additionally, many interactive elements like dropdowns and inputs used `focus:outline-none` without providing alternative focus styles, hindering keyboard accessibility.
**Action:** Always add `aria-label` attributes to buttons containing text that is conditionally hidden on smaller viewports. When removing default focus outlines with Tailwind's `focus:outline-none`, explicitly add custom focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-ig-primary`) to maintain keyboard focus visibility.
